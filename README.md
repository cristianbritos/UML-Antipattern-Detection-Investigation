# UML Antipattern Detection using Machine Learning

## Research Project

Development of a machine learning model to detect design antipatterns in business models represented through UML diagrams and business rules.

## Research Areas

- Machine Learning
- Software Engineering
- UML Modeling
- Business Rules
- Requirements Engineering
- Design Quality

## Problem Statement

Business models represented through UML diagrams frequently contain design flaws and antipatterns that are difficult to identify during requirements and analysis phases.

This project aims to develop a machine learning model capable of detecting these antipatterns early in the software lifecycle.

## Objectives

- Identify UML design antipatterns.
- Build datasets of valid and invalid models.
- Extract structural features from UML diagrams.
- Train classification models.
- Evaluate prediction performance.

## Expected Impact

- Improve software quality.
- Assist analysts and software architects.
- Reduce design defects during early development stages.

## Status

Research in progress.
